Wiki-style website based on the anime Violet Evergarden made in HTML, featuring a chart to depict a character sheet that visually represents key details about each character. The site is enriched with interactive CSS elements, enhancing the user experience by making various sections of the page tactile and responsive to mouse hovers. Additionally, the site includes a unique translation function, allowing users to view the website in the fictional language used within the anime. This feature not only adds authenticity but also immerses fans deeper into the world of Violet Evergarden.
